# Warthunder_E-M_Analyser
本工具包含两个核心程序，旨在通过抓取战争雷霆8111端口的物理数据，为你生成战机能量机动（E-M）包线图。

【前置准备】
1. 启动战争雷霆，进入试飞或者自定义战斗。
2. 将你需要测试的战机飞至预定的测试高度（例如 100 米）。
3. 确保你的游戏能在后台提供本地 8111 端口数据。

------------------------------------------------------
第一阶段：数据采集 —— 使用【黑匣子.exe】
------------------------------------------------------
“黑匣子”是一个后台记录仪，负责高频抓取并记录你的飞行物理参数。

1. 开始记录：在游戏中飞到指定高度并平飞后，双击运行【黑匣子.exe】。
   （此时会弹出一个黑色的命令行窗口，显示正在抓取数据，请保持它在后台运行）
2. 试飞动作：
   - 保持油门固定（通常为WEP）。
   - 保持高度稳定（极其重要！尽量使爬升率接近零）。
   - 在该高度下，进行各种速率的水平盘旋，尽可能覆盖战机在该高度下的所有速度区间与能量状态。
3. 结束记录：试飞结束后，直接关闭【黑匣子.exe】的黑框。
4. 生成文件：程序会在当前目录下自动生成一份 .csv 数据文件。你可以多次试飞生成多个 .csv 文件，分析仪会自动将它们合并。

------------------------------------------------------
第二阶段：数据分析与制图 —— 使用【译码仪.exe】
------------------------------------------------------
“译码仪”是数据解码与可视化终端，负责把海量数据转化为 E-M 性能包线图。

1. 准备文件：确保【译码仪.exe】和刚才生成的所有同机型 .csv 试飞文件放在同一个文件夹内。
2. 启动程序：双击运行【译码仪.exe】，会弹出一个配置窗口。
3. 填写参数：
   - [飞机机型]：填入战机名称（例如 F-16C），将显示在图表标题上。
   - [期望测试高度/油门]：必须与你刚才实际试飞的高度和油门保持一致。
   - [容差参数]：默认值基本已是最优调校，过滤掉非水平飞行的杂波。如果试飞技术不够稳定，可适当调大各数据的容差。
   - [西格玛值]：控制 SEP 等高线的“平滑度”。
     * 数值较大（如 64-72）：线条更圆滑，能自动抹平试飞时的手抖和物理计算杂波，图表更美观，但在精确度方面有所妥协。
     * 数值较小（如 32-48）：线条更锋利骨感，忠实还原数据的每一个细微转折。推荐在拥有海量高质量试飞数据时使用，否则可能会出现数据噪声过大的情况。
   - [混合插值法选项]：
     * 打勾（默认）：采用线性与邻近混合插值法。
     * 不打勾：仅采用线性插值法。
4. 生成图表：点击“生成图表”按钮后稍等片刻 E-M 性能包线图就将渲染完毕。

------------------------------------------------------
【进阶测试指南】
1. 严控操纵品质：
   - 模式建议：强烈推荐在“全真模式（Simulator）”或全真操控下配合摇杆进行采集。历史模式的鼠标瞄准会自动疯狂微调舵面，产生大量无用的配平阻力杂波。
   - 开启阻尼器：建议开启飞控的“阻尼器（Damper/SAS）”模式以稳定机身姿态。
   - 拒绝粗暴操作：操作必须极致平滑、线性。绝对要避免“抽动式蹬舵”（比如 Negative-G），猛烈打满杆或松杆。这类不连续的突变操作会引发极大的瞬时诱导阻力和难以预测的空气压缩效应，导致最终的数据图表上出现难看的“麻点”和等高线断层。
2. 提高样本丰度：
   - 如果你发现生成的图表边缘有锯齿、残缺或其他异常，说明你的试飞数据在某些速度段不够密集。再多飞几圈补足那个速度段的数据，译码仪会自动将新旧 .csv 文件融合，给你生成一张更完美的包线图。
3. 终极极客玩法：
   - 当你觉得自己的试飞操作已经如同机器般精准，且样本量足够庞大时，可尝试在界面中取消勾选“混合插值法”，并将“西格玛值”降低至 48 甚至 36。图表将褪去所有算法的伪装，呈现出战机最原汁原味的气动极限边界。
